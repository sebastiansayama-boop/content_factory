# Content Factory — Research Program: 100 Questions

The 100 questions remain the seed corpus. Their execution order is governed by `docs/32_external_system_research_tree.md`, not by numeric order.

## Current research hierarchy

`Question → Decomposition → Source Map → Evidence → Cross-source Comparison → Mechanism Reconstruction → Verification/Experiment → Contradiction Analysis → Conclusion → Decision → Derived Questions`

Every material global question must be decomposed to at least five levels. Scale deeper when evidence leaves a meaningful mechanism unresolved. "Smallest experiment" applies only after identifying the smallest indivisible sub-question needed for the claim.

## Starting questions — current phase

1. What must Content Factory be able to do to interact with reality outside its own information space?
2. What is an external system, and what makes its state genuinely external?
3. Which classes of external systems have materially different semantics?
4. Which interaction types cross the boundary, and which merely establish information?
5. What is the generic structure of an external action from intent through consequence?

Then follow the tree:

`L0 External World → L1 External Systems → L2 System Classes → L3 Interaction Semantics → L4 External Action → L5 Authority/Execution → L6 Effect/Observation/Verification → L7 State/Time → L8 Uncertainty → L9 Reliability/Recovery → L10 Security → L11 Provenance → L12 Factory Boundary → L13 Generic Capabilities → L14 GitHub`

GitHub questions 71–80 are a concrete instantiation, not the starting abstraction.

## Rules

- Research findings are evidence, not automatic repository truth.
- Conclusions must preserve evidence, inference boundary, confidence and decision.
- Repository-impacting conclusions require post-write verification of artifact, commit, dependencies and research consistency.
- Negative results and unknowns are first-class outcomes.
- The next question is derived from evidence and unresolved boundaries, not an arbitrary implementation roadmap.

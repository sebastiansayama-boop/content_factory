## Review protocol (per image)
- **Visible evidence:** describe only directly observable subject, action, lighting boundaries, shadows, reflections, perspective, composition, motion and texture.
- **Metadata:** separate verified EXIF/author information from visually estimated camera settings; note editing when documented.
- **Confidence:** confirmed / plausible / unknown for each inference.
- **Transferable principle:** one actionable photographic rule with context, not a universal 'AI tell'.
- **Luca comparison:** identify the closest generated scene and specify one controlled variable to change.
- **Result:** record the independent single-image rerun and human decision before promoting a heuristic to an accepted skill.

## Initial verified notes
- The Bangkok street image has documented capture metadata (Nikon D200, ISO 400, 1/125 s, f/5.6, 28 mm), showing the value of distinguishing actual settings from inferred aesthetics.
- The Library of Congress kitchen/grocery source describes a multi-frame documentary sequence including food preparation, workers, portraits and interior overviews. Individual frame numbers must be confirmed visually before detailed comparison.
- The Magnum source is a contact sheet, useful for studying photographic selection; it is not a phone-photo reference.
- These sources span different eras and photographic equipment; do not generalize camera characteristics across them.

# Меню генерации фотографий Луки (ChatGPT + GitHub)

**Статус: меню подготовлено, но НЕ подключено автоматически к генератору изображений и НЕ является веб-интерфейсом.**

Этот слой не заменяет уже существующий `docs/character/character.json`. Он использует его как источник стабильной внешности и ограничивает только изменяемые параметры съёмки. Источники фотонаблюдений: `docs/knowledge/photography_observation_parameters.json`, `docs/skills/natural_photography.md`.

## Как пользоваться в чате

Перед запросом изображения открыть `docs/character/luka_generation_menu.json`. Показать оператору поля **сцена, крупность, камера, поворот головы, взгляд, эмоция, действие, руки, одежда, чувственность, свет, характер съёмки** и предложить три стартовых пресета.

Оператор выбирает пресет и изменяет отдельные поля. Не подменять значения «наиболее фотогеничными»: для разнообразия важнее менять **действие и взгляд**, а не только фон. Генерация запускается только после выбора, с актуальными изображениями Луки как визуальной опорой, когда они доступны.

Простой пример выбора: **«Лука → Улица — живой смех → оставляем остальные настройки»**.

## Антиповтор

Перед генерацией сравнить настройки трёх последних кадров. Не повторять один и тот же наклон головы, подпорку головы ладонью, полуулыбку и прямой взгляд как стандарт. Поставить разные триады: улица (смех, взгляд в сторону, движение), кухня (внимание к действию, взгляд вниз), балкон (сдержанный флирт, полуоборот).

Если история настроек ещё не сохранена, не утверждать, что антиповтор выполнился автоматически. Использовать видимые предыдущие изображения для ручной оценки.

## Сохранение

Для каждого принятого кадра сохранить запись на базе `request_template` и `review_template`: значения полей, ссылку/хеш реального файла, ID генерации при наличии, редакторское решение, место хранения оригинала и последнюю ревизию профиля.

**Доступность:** ChatGPT может опираться на этот файл только когда его содержимое передано в активную беседу или явно прочитано из GitHub. Одна запись JSON в репозитории не заставляет встроенную генерацию ChatGPT автоматически загружать настройки. Не обещать, что пользовательский текстовый промпт гарантированно удержит лицо: это задача визуальных референсов и QC.

**Граница:** для Content Factory в ветке PR #179 сценарий персонажа сейчас использует импорт файлов; прямого подключения этого меню к `AssetExecutor` нет. Не менять веб-интерфейс Content Factory без отдельного запроса.

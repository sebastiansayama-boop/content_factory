# Codex / agent entry point — Content Factory

Прежде чем выполнять работу, прочитай:
1. `docs/CONTENT_FACTORY_PRODUCT_DEFINITION.md` — текущее назначение приложения и границы.
2. `docs/CODEX_PRODUCT_EXECUTION.md` — приёмочные сценарии и порядок работы.
3. `05_decision/2026-10-08-personal-first-product-scope.md` — явное решение владельца.
4. `RULES.md`, `docs/25_chat_repository_operating_protocol.md` и `docs/v1.0_release.md` — действующие правила и релизные границы.

Content Factory — общее приложение. «Лука» — первый контентный проект, **не** отдельное приложение или новая архитектура. Первое использование — личное; коммерческая платформа только после отдельного решения и валидации спроса.

Правило исполнения: реальный сценарий → наблюдаемая ошибка → минимальное исправление → тест → повторная проверка. Сохраняй работающий код и provenance, не удаляй файлы, не добавляй платные API и не отправляй материалы в реальные соцсети без разрешения. Отличай локальный статус от внешне подтверждённой доставки, а текстовый документ — от работоспособной функции.
